**Questão 3 - Configuração de Variáveis de Ambiente**

Um arquivo settings_prod.py do Django precisa acessar as credenciais do RDS MySQL configuradas no Elastic Beanstalk. As variáveis foram definidas no console do EB como:

- DB_HOST = meu-banco.xxxxxxxx.us-east-1.rds.amazonaws.com

- DB_NAME = django_prod

- DB_USER = admin

- DB_PASSWORD = senha_segura_123

- DB_PORT = 3306

Qual código no settings_prod.py recupera corretamente essas configurações?

python

### Opção A

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'django_prod',
        'USER': 'admin',
        'PASSWORD': 'senha_segura_123',
        'HOST': 'meu-banco.xxxxxxxx.us-east-1.rds.amazonaws.com',
        'PORT': '3306',
    }
}
```


### Opção B

```python
import os
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': os.environ.get('DB_NAME', 'django_prod'),
        'USER': os.environ.get('DB_USER', 'admin'),
        'PASSWORD': os.environ.get('DB_PASSWORD'),
        'HOST': os.environ.get('DB_HOST'),
        'PORT': os.environ.get('DB_PORT', '3306'),
    }
}
```

### Opção C

```python
import json, boto3
ssm = boto3.client('ssm')
params = ssm.get_parameters(Names=['DB_HOST', 'DB_NAME', 'DB_USER', 'DB_PASSWORD', 'DB_PORT'])
```

### Opção D

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': '{{DB_NAME}}',
        'USER': '{{DB_USER}}',
        'PASSWORD': '{{DB_PASSWORD}}',
        'HOST': '{{DB_HOST}}',
        'PORT': '{{DB_PORT}}',
    }
}
```

a) Opção A

b) Opção B

c) Opção C

d) Opção D 

e) Todas


**Questão 4 - Configuração do S3 com django-storages**

Uma aplicação Django precisa armazenar arquivos de mídia no Amazon S3. O desenvolvedor instalou django-storages e boto3, e configurou as variáveis de ambiente no EB. O arquivo settings_prod.py contém as configurações do S3.

Considerando que a variável AWS_STORAGE_BUCKET_NAME está configurada no EB com o valor meu-app-prod-media, qual configuração completa é necessária no settings_prod.py?

### Opção A

```python
DEFAULT_FILE_STORAGE = 'storages.backends.s3boto3.S3Boto3Storage'
AWS_STORAGE_BUCKET_NAME = 'meu-app-prod-media'
```

### Opção B

```python
AWS_ACCESS_KEY_ID = os.environ.get('AWS_ACCESS_KEY_ID')
AWS_SECRET_ACCESS_KEY = os.environ.get('AWS_SECRET_ACCESS_KEY')
AWS_STORAGE_BUCKET_NAME = os.environ.get('AWS_STORAGE_BUCKET_NAME')
DEFAULT_FILE_STORAGE = 'storages.backends.s3boto3.S3Boto3Storage'
```

### Opção C
```python
import os
AWS_ACCESS_KEY_ID = os.environ.get('AWS_ACCESS_KEY_ID')
AWS_SECRET_ACCESS_KEY = os.environ.get('AWS_SECRET_ACCESS_KEY')
AWS_STORAGE_BUCKET_NAME = os.environ.get('AWS_STORAGE_BUCKET_NAME')
AWS_S3_REGION_NAME = os.environ.get('AWS_S3_REGION_NAME', 'us-east-1')
AWS_S3_OBJECT_PARAMETERS = {'CacheControl': 'max-age=86400'}
DEFAULT_FILE_STORAGE = 'storages.backends.s3boto3.S3Boto3Storage'
```

### Opção D
```python
AWS_STORAGE_BUCKET_NAME = os.environ.get('AWS_STORAGE_BUCKET_NAME')
AWS_S3_CUSTOM_DOMAIN = f'{AWS_STORAGE_BUCKET_NAME}.s3.amazonaws.com'
STATIC_URL = f'https://{AWS_S3_CUSTOM_DOMAIN}/static/'
MEDIA_URL = f'https://{AWS_S3_CUSTOM_DOMAIN}/media/'
```

a) Opção A

b) Opção B

c) Opção C

d) Opção D

e) Todas

a) Configurar um volume EBS adicional e montá-lo na instância EC2
